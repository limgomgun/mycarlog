# mycarlog (차계부)

**바로 접속: https://limgomgun.github.io/mycarlog/**

주유·정비·세차·보험 등 차량 비용과 연비, 소모품 교체 주기를 관리하는 단일 HTML 웹앱입니다.
빌드나 서버 없이 `index.html` 하나로 동작하며, 기록은 **사용하는 브라우저(localStorage)에만** 저장됩니다.
서버로 전송되는 데이터는 없고, 다른 사람이 링크를 열어도 내 기록은 보이지 않아요.

## 기능

### 기록
- **분류 7종:** 주유·충전, 정비·부품, 세차, 보험, 세금·검사, 주차·통행료, 기타
- **주유 기록:** 주유량, 단가, 주유소, 가득 주유 여부. 주유소를 고르면 그곳의 마지막 단가가 채워져요.
- **주행거리:** 입력하면 직전 기록보다 작은지 확인해 줘요.
- **정비 기록:** 교체한 소모품·부품을 눌러서 여러 개 선택해요(알약 버튼).
- 기록 수정·삭제, 내용 검색, 분류 필터, 월 이동

### 통계
- 이번 달 / 올해 / 전체 기간별 지출 합계와 전월 대비
- 연료비, 정비비, 평균 연비(가득 주유 기준 구간 계산), km당 비용
- 월별 지출 차트(분류별 누적 막대), 분류별 지출 비율

### 소모품·부품 관리
- 엔진오일, 미션오일, 브레이크오일, 냉각수, 에어컨 필터, 와이퍼, 타이어, 브레이크 패드, 배터리 기본 주기 제공
- 주기는 **km와 개월 중 먼저 오는 쪽**이 기준이며, 항목별로 직접 바꿀 수 있어요.
- 정비 기록에서 체크하면 마지막 교체일·주행거리가 자동 갱신되고, 교체 시기 지남 / 곧 교체 상태와 남은 거리·기간을 보여 줘요.
- 항목 카드의 **교체** 버튼으로 바로 정비 기록 입력

### 내 차 정보
- 차 이름, 연료(휘발유·경유·LPG·하이브리드·전기), 번호판, **차량 사진**
- **차 가져온 날**을 넣으면 상단에 "2026.03.01 가져옴 · 239일째 (7개월)"처럼 며칠째 타고 있는지 표시해요.
- 사진을 등록하면 상단 카드 배경으로 크게 표시돼요.
- 누적 주행거리는 주행거리 계기판 스타일로 표시

### 가져오기·내보내기
- **증명서 사진으로 가져오기:** 자동차 기록 증명서(마일클 등) 캡처를 올리면 브라우저 안에서 글자를 읽어(Tesseract.js) 월별 날짜·주행거리·교체 항목을 미리보기로 보여 주고, 확인 후 기록으로 저장해요. 사진 선택, 끌어다 놓기, 붙여넣기를 지원하고 글자 직접 붙여넣기도 가능해요.
- **엑셀·CSV 가져오기:** `.xlsx` `.xls` `.csv`를 읽어요. 열 이름을 보고 자동으로 맞추고 필요하면 직접 고를 수 있어요. 한글(CP949) CSV, 엑셀 날짜 칸, 여러 날짜 표기, 제목 줄이 있는 파일을 지원하고 중복 기록은 제외해요.
- **계좌이체·카드 내역 가져오기:** 은행 앱·홈페이지에서 받은 입출금 내역 파일(`.xlsx` `.csv`)이나 거래내역 캡처 사진을 올리면 **출금 내역만** 읽어요. 주유소·정비소·세차·보험·세금·주차 같은 가맹점 이름으로 분류를 추측하고, 차량 관련으로 보이는 기록만 미리 선택해요. 분류와 내용은 미리보기에서 고칠 수 있어요.
- **정비 명세서 가져오기:** 정비소 명세서(견적서) 사진이나 글자를 올리면 날짜, 주행거리, 교체 항목, 합계 금액으로 정비 기록 1건을 만들어요.
- **양식 받기:** 가져오기 열 이름에 맞춘 빈 CSV 양식(예시 3줄 포함)을 내려받아요.
- **CSV 내보내기:** 전체 기록을 CSV로 저장(백업용). 내보낸 파일은 그대로 다시 가져올 수 있어요.

### 화면
- 리퀴드 글라스(반투명 유리) 스타일, 라이트·다크 모드 자동 전환
- 데스크톱은 2단(통계·목록 + 입력 폼), 모바일은 1단
- 앱 스타일로 통일한 드롭다운과 달력 선택기
- 글꼴 선택(IBM Plex, Noto Sans KR, Gothic A1, 나눔고딕, 고운돋움, 나눔명조, 기기 기본)
- 첫 실행 때는 예시 데이터를 보여 주고, 첫 기록을 저장하면 사라져요.
- 파비콘, 홈 화면 아이콘, 링크 공유 미리보기 이미지(Open Graph)

## 사용 시 알아둘 점
- 기록은 이 브라우저에만 저장돼요. 브라우저 데이터를 지우거나 다른 기기에서 열면 보이지 않으니 **가끔 CSV로 내보내 두세요.**
- 증명서 사진·`.xlsx` 읽기는 처음 한 번 읽기 도구를 내려받으므로 인터넷 연결이 필요해요. CSV 가져오기는 연결 없이 동작해요.
- 사진 글자 인식은 완벽하지 않아서, 가져오기 전에 미리보기에서 날짜·주행거리·항목을 확인해 주세요.
- 증명서 형식은 마일클 화면 기준으로 만들었어요. 계좌이체 내역은 금액이 있는 출금만 가져오고, 가맹점 이름으로 분류를 추측하므로 분류를 꼭 확인해 주세요.

## 배포 (GitHub Pages)
1. 저장소 루트에 파일을 올립니다.
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `/ (root)`
3. 커스텀 도메인은 Settings → Pages → Custom domain에 입력하고, 도메인 업체에서 CNAME을 `limgomgun.github.io`로 지정하세요.
